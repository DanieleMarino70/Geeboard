Quickstart Guide

Learn how to install, configure, and initialize Geeboard telemetry dashboards in your Next.js and Node.js projects within minutes.

01

Installation

Install the core engine and React runtime adapters. Geeboard modules are lightweight with zero native C++ bindings for instant edge compilation.

$ pnpm add @geeboard/core @geeboard/react
lightbulb
Pro Tip: React Server Components RSC READY

Geeboard supports zero-runtime streaming for App Router out-of-the-box. Telemetry traces stream directly over standard HTTP/2 chunked transfer without triggering client component re-renders.

02

Setting up the Provider

Wrap your application hierarchy with the GeeboardProvider component to inject client-side session contexts.

code app/providers.tsx TSX 
1import { GeeboardProvider } from '@geeboard/react';
2
3export function AppProviders({ children }: { children: React.ReactNode }) {
4  return (
5    <GeeboardProvider apiKey={process.env.GEEBOARD_API_KEY}>
6      {children}
7    </GeeboardProvider>
8  );
9}
warning
Environment Variables Security ALERT

Never prefix secret ingest keys with NEXT_PUBLIC_ unless using scoped read-only ingest tokens. Private service tokens leaked to the client bundle can permit unauthorized telemetry injection.

03

Initializing Telemetry Client

Verify your active telemetry connection by sending a heartbeat ping from your terminal or client component:

terminal HEALTH CHECK
200 OK
$ npx geeboard-cli ping --target=local
✔ Connected to Geeboard Flight Deck daemon [v1.2.0-beta] (lat: 1.4ms)
